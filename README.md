# Программа "Чатик"
## 1. Постановка задачи
   + консольная программа
   + регистрация пользователей - логин, пароль, имя
   + вход в чат по логину/паролю
   + отправка сообщений конкретному пользователю
   + обмен сообщениями между всеми пользователями чата одновременно
## 2. Описание выбранного решения
     + При запуске программы отображается **Основное меню**:
         1.  Регистрация пользователя
         2.  Вход в чат (если уже прошли регистрацию)
     + При переходе на регистрацию пользователь вводит логин, пароль и имя.</br>
       Логин при этом не должен совпадать с одним из созданных (программа оповестит об этом)
     + При переходе на **Вход в чат** отображается подменю:
         1. Вывести список доступных логинов
         2. Вход по логину
         3. Возврат на основное меню
      + Вывести список доступных логинов - выводит список логинов
      + Вход по логину - вводятся логин и пароль (программа сверяет их и если введены верно пропускает в следующее подменю):
         1. Вывести список доступных логинов
         2. Отправка сообщений одному пользователю
         3. Отправка сообщения всем пользователям
         4. Вывести список сообщений для меня
         5. Возврат на предыдущее меню
      + Вывести список доступных логинов - выводит список логинов
      + Отправка сообщений одному пользователю - ввод логина и сообщения (проверяется есть ли такой логин)
      + Отправка сообщения всем пользователям - ввод сообщения
      + Вывести список сообщений для меня - выводит сообщения получателем которых является залогиненный сотрудник
