# Программа "Чатик"
## 1. Постановка задачи
   + консольная программа
   + регистрация пользователей - логин, пароль, имя
   + вход в чат по логину/паролю
   + отправка сообщений конкретному пользователю
   + обмен сообщениями между всеми пользователями чата одновременно
## 2. Описание выбранного решения
   + При запуске программы отображается **Основное меню**:
       + Регистрация пользователя
       + Вход в чат (если уже прошли регистрацию)
   + При переходе на регистрацию пользователь вводит логин, пароль и имя.</br>
       Логин при этом не должен совпадать с одним из созданных (программа оповестит об этом)
   + При переходе на **Вход в чат** отображается подменю:
       + Вывести список доступных логинов
       + Вход по логину
       + Возврат на основное меню
   + Вывести список доступных логинов - выводит список логинов
   + Вход по логину - вводятся логин и пароль (программа сверяет их и если введены верно пропускает в следующее подменю):
        + Вывести список доступных логинов
        + Отправка сообщений одному пользователю
        + Отправка сообщения всем пользователям
        + Вывести список сообщений для меня
        + Возврат на предыдущее меню
   + Вывести список доступных логинов - выводит список логинов
   + Отправка сообщений одному пользователю - ввод логина и сообщения (проверяется есть ли такой логин)
   + Отправка сообщения всем пользователям - ввод сообщения
   + Вывести список сообщений для меня - выводит сообщения получателем которых является залогиненный пользователь

## 3. Описание пользовательских типов и функций
1. Классы:
    + **User** - для записи данных при регистрации пользователя в программе (логин, пароль и имя). </br> В main задается фиксированное количество сотрудников.</br> Создается unique_ptr указанного размера.
    + **Messages** - для хранения данных о сообщениях (отправитель, получатель, текст сообщения). </br> Все сообщения хранятся в векторе типа данного класса.
2. Функции - хранятся в отдельных .cpp и .h файле Functions:
    + **NewUser** - функция для создания нового пользователя. </br> Не дает ввести повторяющийся логин.
    + **mainMenu** - основное меню программы
    + **submenuRegistration** - подменю регистрации пользователей. В ней вызывается функция **NewUser**. </br> Когда доходит до ограничения количества - выдает соответствующее сообщение. </br> Для выхода из подменю регистрации вводится символ отличный от 'Y'. 
    + **submenuMessage** - подменю входа пользователя в систему отправки сообщений. </br> Можно вывести список всех логинов пользователей и войти в подменю отправки сообщений (выполняется проверка логина и пароля - если введено верно то пропускает в следующее подменю).
    + **submenuSending** - подменю сообщений. В нем можно отправить сообщение одному пользователю или всем сразу, а также посмотреть полученные сообщения.
